# Machine Learning From Scratch

This repository contains my implementations of machine learning algorithms from scratch using NumPy.

The goal of this project is to understand the mathematics behind machine learning algorithms instead of treating them as black boxes.

## Implemented Algorithms

- ✅ Linear Regression
- ✅ Logistic Regression
- ✅ Support Vector Machine (SVM)
- ✅ Lasso Regression

More algorithms will be added as I continue learning.
